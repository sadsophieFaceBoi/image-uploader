Manual API Harness

Image Uploader Test Bench

Use this page to exercise the API without Postman or curl. It runs directly against the current server, keeps your auth token in local storage for convenience, and lets you upload, replace, list, preview, and delete images from the same screen.

GET api/media/images/health POST api/media/upload/:folder PUT api/media/upload/:folder/:filename DELETE api/media/upload/:folder/:filename GET api/media/images/list/:folder GET api/media/images/:folder/:filename
